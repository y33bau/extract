# Warownia Popiołów

Izometryczny dark fantasy extraction RPG w duchu Soulsborne, ze światem NightBrand.

**Silnik:** Godot 4.7.2 (folder `godot/`). Granie: plik `.exe` z eksportu (autor dostaje zip). Prototyp w JavaScript (`zrodlo/`, `dist/WAROWNIA_POPIOLOW.html`) to archiwum.

**Praca nad grą:** zasady `CLAUDE.md`, start `docs/START_TUTAJ.md`, kompas `docs/FUNDAMENT.md`, dziennik `docs/DZIENNIK.md`. Test: `python3 narzedzia/testy.py godot`.

Sterowanie (klawiatura / pad): WASD / lewy drążek ruch, mysz / prawy drążek celowanie, LPM / RB lub X combo i riposta, PPM / LB parowanie i blok, Spacja / B unik, Q / Y łuk, E / A przeszukaj, 1-2-3 / krzyżak ↑←→ mikstury, F / krzyżak ↓ pochodnia, G / R3 zrzut sakwy, Tab / Back sakwa. W menu: A zatwierdza, B wraca, LB/RB zakładki.
