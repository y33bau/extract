# Warownia Popiołów

Izometryczny dark fantasy extraction RPG w duchu Soulsborne, ze światem NightBrand.

**Granie:** otwórz `dist/WAROWNIA_POPIOLOW.html` (albo `TEST_WAROWNIA_POPIOLOW.bat`). Działa offline.

**Praca nad grą:** źródła w `zrodlo/`, budowa: `python3 narzedzia/zbuduj.py`. Zasady: `CLAUDE.md`, plany i pomysły: `docs/`.

Sterowanie: WASD ruch, LPM combo / riposta, PPM parowanie / blok, Spacja unik, Q łuk, E przeszukaj, 1/2/3 mikstury, TAB sakwa.
